## Sobre

Sou **Mardoqueu Martins** e estou me preparando para atuar como **Desenvolvedor Full Stack Júnior**. Este repositório registra minha evolução: anotações diárias, exercícios, desafios e links para os projetos entregues a cada semana.

O plano segue uma premissa simples: em 2026, o júnior não compete com a IA escrevendo código básico. Ele é contratado por **entender o código, revisar o que a IA gera, entregar produto completo no ar e integrar IA em aplicações reais.** Cada etapa da trilha foi pensada para provar essas quatro coisas.

## Método de estudo

Rotina de segunda a sexta. Fins de semana são livres e não quebram a sequência.

**Dia de aula** (segunda a quinta)

1. **Aquecimento:** explicar em voz alta o conteúdo do dia anterior, sem consultar.
2. **Aula:** um vídeo curto sobre o tema, com anotações.
3. **Conceito:** entender o problema que o tema resolve, com analogia e exemplo de código.
4. **Exercícios:** seis exercícios em ordem crescente de dificuldade, commitados aqui.
5. **Desafio e resumo:** um desafio extra e um resumo escrito com minhas palavras.

**Dia de projeto** (sexta)

1. Entender o problema real antes de codar.
2. Construir atendendo aos requisitos.
3. Validar os critérios de pronto.
4. Publicar (repositório + deploy) e compartilhar no LinkedIn.

## Como usar

Requisito: [Node.js LTS](https://nodejs.org/).

```bash
git clone https://github.com/mardoqueugmartins/fullstack-journey.git
cd fullstack-journey

# executar um exercício
node mes-01-fundamentos/semana-03-javascript-logica/exercicios/condicionais-validar-saida.js
```

Para usar a trilha interativa, abra `docs/trilha.html` no navegador. O progresso fica salvo localmente.

## Convenção de commits

Este repositório segue [Conventional Commits](https://www.conventionalcommits.org/pt-br/):

| Tipo | Uso | Exemplo |
|---|---|---|
| `feat` | exercício, desafio ou conteúdo novo | `feat(semana-03): resolve FizzBuzz` |
| `fix` | correção de solução | `fix(semana-03): corrige cálculo de ano bissexto` |
| `docs` | anotações e READMEs | `docs(semana-01): adiciona resumo do dia 2` |
| `refactor` | melhoria sem mudar comportamento | `refactor(semana-03): simplifica condicionais` |
| `chore` | configuração e manutenção | `chore: atualiza .gitignore` |
