## Aulas

### Dia 11 · Variáveis e tipos

Variáveis guardam valores. let pode mudar, const não pode ser reatribuída. Os tipos básicos são string, number, boolean, null, undefined e object.

> 💡 **Analogia:** Variável é um pote com etiqueta: a etiqueta é o nome, o que está dentro é o valor.

**Aula:** [buscar vídeo no YouTube](https://www.youtube.com/results?search_query=javascript%20vari%C3%A1veis%20e%20tipos%20de%20dados)

**Exercícios**

- [ ] Declare nome, idade e ehEstudante e imprima com template string.
- [ ] Converta '42' em número e some 8.
- [ ] Use typeof em 6 valores diferentes e anote os resultados.
- [ ] Troque o valor de duas variáveis entre si.
- [ ] Calcule o preço final de um produto com 15% de desconto.
- [ ] Explique num comentário a diferença entre null e undefined.

**Desafio:** Crie um cartão de visita no console usando só uma template string de várias linhas.

### Dia 12 · Operadores e condicionais

Operadores calculam e comparam. if/else e switch escolhem caminhos diferentes conforme as condições.

> 💡 **Analogia:** É o GPS: se a rua estiver fechada, vire à direita; senão, siga reto.

**Aula:** [buscar vídeo no YouTube](https://www.youtube.com/results?search_query=javascript%20if%20else%20switch%20operadores%20l%C3%B3gicos)

**Exercícios**

- [ ] Diga se um número é par ou ímpar.
- [ ] Encontre o maior entre 3 números.
- [ ] Classifique uma nota em A, B, C ou D.
- [ ] Diga se um ano é bissexto.
- [ ] Aplique desconto progressivo conforme o valor da compra.
- [ ] Use switch para dizer se um dia é útil ou fim de semana.

**Desafio:** Explique == vs === com 3 exemplos que dão resultados diferentes.

### Dia 13 · Laços de repetição

for, while e for...of repetem ações até uma condição parar. break interrompe e continue pula para a próxima volta.

> 💡 **Analogia:** É a máquina de lavar: repete o ciclo até a roupa ficar limpa ou o tempo acabar.

**Aula:** [buscar vídeo no YouTube](https://www.youtube.com/results?search_query=javascript%20for%20while%20loops%20exerc%C3%ADcios)

**Exercícios**

- [ ] Imprima de 1 a 100.
- [ ] Mostre a tabuada de um número.
- [ ] Some todos os pares até 1000.
- [ ] Resolva o FizzBuzz.
- [ ] Conte as vogais de uma frase.
- [ ] Diga se um número é primo.

**Desafio:** Desenhe uma pirâmide de asteriscos com altura n no console.

### Dia 14 · Lógica e depuração

Programar é quebrar um problema grande em passos pequenos. Depurar é descobrir onde o programa faz algo diferente do que você imagina.

> 💡 **Analogia:** Depurar é trabalho de detetive: você junta pistas até achar o culpado, sem chutar.

**Aula:** [buscar vídeo no YouTube](https://www.youtube.com/results?search_query=como%20debugar%20javascript%20devtools%20breakpoint)

**Exercícios**

- [ ] Escreva pseudocódigo antes de resolver 2 problemas.
- [ ] Coloque um breakpoint num laço no DevTools e acompanhe as variáveis.
- [ ] Peça à IA um código com 3 bugs escondidos e encontre sem ajuda.
- [ ] Inverta uma string sem usar reverse().
- [ ] Diga se uma palavra é palíndromo.
- [ ] Conte quantas vezes uma letra aparece numa frase.

**Desafio:** Resolva 3 problemas iniciantes no Beecrowd ou Exercism em JavaScript.

**Requisitos**

- [ ] Cálculo com juros compostos

- [ ] Mensagens claras para entradas inválidas

- [ ] Código organizado em blocos com nomes claros

**Critérios de pronto**

- [ ] Roda com node orcamento.js
- [ ] 5 casos testados à mão e anotados no README
