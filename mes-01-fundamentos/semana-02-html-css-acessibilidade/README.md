## Aulas

### Dia 6 · HTML semântico

Tags semânticas (header, nav, main, article, section, footer) dizem o significado do conteúdo, não só a aparência. Isso ajuda o Google, os leitores de tela e outros devs.

> 💡 **Analogia:** É etiquetar as caixas na mudança: 'cozinha', 'quarto'. Qualquer um sabe onde está cada coisa sem abrir.

**Aula:** [buscar vídeo no YouTube](https://www.youtube.com/results?search_query=html%20sem%C3%A2ntico%20acessibilidade)

**Exercícios**

- [ ] Refaça uma página feita só com div usando tags semânticas.
- [ ] Organize a hierarquia de títulos h1, h2 e h3 sem pular níveis.
- [ ] Crie um formulário com label ligado a cada input.
- [ ] Escreva alt descritivo para 5 imagens (e alt vazio para as decorativas).
- [ ] Monte uma tabela com thead, tbody e th com scope.
- [ ] Valide a página no validator.w3.org e corrija os erros.

**Desafio:** Navegue pela sua página só com a tecla Tab e anote onde o foco some ou fica confuso.

### Dia 7 · Box model e Flexbox

Todo elemento é uma caixa: conteúdo, padding, borda e margem. Flexbox organiza itens em linha ou coluna e distribui o espaço entre eles.

> 💡 **Analogia:** Flexbox é uma prateleira: você decide se os livros ficam juntos à esquerda, espalhados ou no centro.

**Aula:** [buscar vídeo no YouTube](https://www.youtube.com/results?search_query=css%20flexbox%20na%20pr%C3%A1tica)

**Exercícios**

- [ ] Monte uma navbar com logo à esquerda e links à direita.
- [ ] Centralize um card na vertical e na horizontal.
- [ ] Faça 3 cards que quebram linha com flex-wrap.
- [ ] Troque margens por gap entre itens.
- [ ] Explique num comentário o que box-sizing: border-box muda.
- [ ] Jogue o Flexbox Froggy até o nível 24.

**Desafio:** Recrie o cabeçalho de um site famoso usando só flexbox.

### Dia 8 · CSS Grid e responsividade

Grid organiza em linhas e colunas ao mesmo tempo. Media queries e unidades relativas adaptam o layout a qualquer tela, começando pelo celular.

> 💡 **Analogia:** Grid é a planta da casa: você define os cômodos antes de colocar os móveis.

**Aula:** [buscar vídeo no YouTube](https://www.youtube.com/results?search_query=css%20grid%20layout%20responsivo)

**Exercícios**

- [ ] Galeria com grid-template-columns: repeat(auto-fit, minmax(200px, 1fr)).
- [ ] Layout com header, sidebar, main e footer usando grid-template-areas.
- [ ] Converta um layout desktop para mobile-first com media queries.
- [ ] Troque px por rem nas fontes e espaçamentos.
- [ ] Torne uma imagem responsiva sem distorcer.
- [ ] Complete o Grid Garden.

**Desafio:** Monte um layout de dashboard que vira uma coluna só em 400px de largura.

### Dia 9 · Acessibilidade e performance

Acessibilidade garante que todos usem o site (contraste, teclado, leitor de tela). Performance é carregar rápido. O Lighthouse mede os dois.

> 💡 **Analogia:** É a rampa ao lado da escada: não atrapalha ninguém e permite que todos entrem.

**Aula:** [buscar vídeo no YouTube](https://www.youtube.com/results?search_query=lighthouse%20acessibilidade%20web%20performance)

**Exercícios**

- [ ] Rode o Lighthouse num site seu e anote 5 problemas.
- [ ] Corrija o contraste de cores com um verificador de contraste.
- [ ] Deixe o foco visível em todos os botões e links.
- [ ] Converta imagens para webp e use loading=lazy.
- [ ] Adicione aria-label em botões que só têm ícone.
- [ ] Respeite prefers-reduced-motion nas animações.

**Desafio:** Chegue a 90+ em Acessibilidade num site real que você já entregou.

## Dia 10 · Projeto: Landing page de conversão

**Problema:** Um negócio local (escritório, clínica ou restaurante) precisa de uma página que transforme visita em contato. Faça como se fosse para um cliente de verdade.

**Requisitos**

- [ ] HTML semântico, sem framework de CSS
- [ ] Responsiva de 360px a 1440px
- [ ] Formulário acessível com validação nativa
- [ ] Botão de WhatsApp visível no celular
- [ ] Seção de prova social e chamada para ação clara

**Critérios de pronto**

- [ ] Lighthouse 90+ em Performance, Acessibilidade e SEO
- [ ] Publicada no GitHub Pages ou Vercel
- [ ] README com prints e decisões de design

**Entrega:** _link do repositório ou deploy_
