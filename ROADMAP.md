# Roadmap · Full Stack em 6 meses

26 semanas · 130 dias úteis · 104 aulas + 26 projetos.

Cada semana tem 4 dias de aula (segunda a quinta) e 1 dia de projeto (sexta). O último projeto de cada mês é o **chefe do mês** 🏆: ele integra tudo o que foi estudado no período.

[← Voltar ao README](./README.md)

Terminal, Git e GitHub, HTML semântico, CSS moderno, acessibilidade, JavaScript, DOM e uso responsável de IA.

3. GitHub, branches e Pull Request

5. **Projeto:** Landing page de conversão — Um negócio local (escritório, clínica ou restaurante) precisa de uma página que transforme visita em contato. Faça como se fosse para um cliente de verdade.

### [Semana 05 · DOM, eventos e dados no navegador](./mes-01-fundamentos/semana-05-dom-eventos/README.md)

1. Manipulando o DOM
2. Eventos

4. localStorage e estado
5. **Projeto (chefe do mês 🏆):** Gerenciador de prazos — Autônomos como advogados e contadores perdem prazos em planilhas. Crie um app web de prazos que funcione no celular.
