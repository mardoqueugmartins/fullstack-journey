## Aulas

### Dia 31 · Complexidade (Big-O)

Big-O mede como o tempo cresce quando a entrada cresce: O(1) constante, O(n) linear, O(n²) quadrático, O(log n) logarítmico.

> 💡 **Analogia:** Achar um nome na lista telefônica página por página é O(n). Abrir no meio e cortar pela metade é O(log n).

**Aula:** [buscar vídeo no YouTube](https://www.youtube.com/results?search_query=big%20o%20notation%20explicado%20portugu%C3%AAs)

**Exercícios**

- [ ] Classifique a complexidade de 6 trechos de código.
- [ ] Reescreva uma busca de duplicados de O(n²) para O(n) com Set.
- [ ] Meça com console.time um array de 1.000 e de 100.000 itens.
- [ ] Implemente busca linear.
- [ ] Implemente busca binária.
- [ ] Explique por que ordenar custa O(n log n).

**Desafio:** Resolva o two-sum em O(n).

### Dia 32 · Pilha, fila e hash map

Pilha: o último a entrar sai primeiro. Fila: o primeiro a entrar sai primeiro. Hash map: busca por chave em tempo constante.

> 💡 **Analogia:** Pilha de pratos, fila do banco e armário com chaves numeradas.

**Aula:** [buscar vídeo no YouTube](https://www.youtube.com/results?search_query=estrutura%20de%20dados%20pilha%20fila%20javascript)

**Exercícios**

- [ ] Implemente uma classe Stack.
- [ ] Valide parênteses balanceados com pilha.
- [ ] Implemente uma fila.
- [ ] Conte a frequência de palavras com Map.
- [ ] Encontre o primeiro caractere que não se repete.
- [ ] Implemente desfazer e refazer com duas pilhas.

**Desafio:** Implemente um cache LRU usando Map.

### Dia 33 · Recursão e ordenação

Recursão é uma função que chama a si mesma com um problema menor até chegar no caso base. Ordenação organiza dados (bubble, merge, quick).

> 💡 **Analogia:** Bonecas russas: você abre uma e tem outra menor dentro, até a última que não abre.

**Aula:** [buscar vídeo no YouTube](https://www.youtube.com/results?search_query=recurs%C3%A3o%20javascript%20explicado)

**Exercícios**

- [ ] Fatorial recursivo.
- [ ] Fibonacci com memoização.
- [ ] Soma de um array aninhado.
- [ ] Bubble sort.
- [ ] Merge sort.
- [ ] Percorra uma árvore de pastas representada como objeto.

**Desafio:** Desenhe a pilha de chamadas de fatorial(4).

### Dia 34 · Problemas estilo entrevista

Método: entender, criar exemplos, força bruta, otimizar, testar e falar em voz alta. O entrevistador avalia o raciocínio, não só a resposta.

> 💡 **Analogia:** É cozinhar em programa de TV: o jurado quer ver você explicando cada passo.

**Aula:** [buscar vídeo no YouTube](https://www.youtube.com/results?search_query=como%20resolver%20problemas%20de%20algoritmos%20entrevista%20t%C3%A9cnica)

**Exercícios**

- [ ] Diga se duas palavras são anagramas.
- [ ] Agrupe anagramas de uma lista.
- [ ] Maior soma de subarray (Kadane).
- [ ] Rotacione um array k posições.
- [ ] Junte dois arrays ordenados.
- [ ] Mova os zeros para o fim mantendo a ordem.

**Desafio:** Grave 10 minutos resolvendo um problema em voz alta e assista depois.
