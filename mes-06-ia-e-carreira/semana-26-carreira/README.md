## Aulas

### Dia 126 · README e portfólio

Um README que vende tem problema, solução, demonstração, stack, decisões, como rodar e aprendizados.

> 💡 **Analogia:** README é a vitrine da loja: ninguém entra se a vitrine está vazia.

**Aula:** [buscar vídeo no YouTube](https://www.youtube.com/results?search_query=como%20fazer%20readme%20profissional%20github)

**Exercícios**

- [ ] README completo do projeto final.
- [ ] GIF de demonstração.
- [ ] Fixe os 6 melhores repositórios.
- [ ] Atualize seu site de portfólio.
- [ ] Arquive repositórios fracos.
- [ ] Grave um vídeo de 2 minutos do projeto.

**Desafio:** Peça feedback de um dev sobre o seu GitHub.

### Dia 127 · LinkedIn e currículo

Currículo de uma página com os projetos como experiência, números e as palavras-chave da vaga. LinkedIn ativo com posts.

> 💡 **Analogia:** Currículo é trailer de filme: mostra as melhores cenas em 2 minutos.

**Aula:** [buscar vídeo no YouTube](https://www.youtube.com/results?search_query=curr%C3%ADculo%20desenvolvedor%20j%C3%BAnior%20sem%20experi%C3%AAncia)

**Exercícios**

- [ ] Descreva 3 projetos no formato problema, ação e resultado.
- [ ] Adapte o currículo para 1 vaga real.
- [ ] Reescreva o título do LinkedIn.
- [ ] Publique um post sobre o projeto final.
- [ ] Conecte-se com 20 devs e recrutadores.
- [ ] Candidate-se a 5 vagas.

**Desafio:** Escreva uma mensagem curta para um recrutador.

### Dia 128 · Entrevista técnica

Explique os projetos com o método STAR, resolva problemas em voz alta e admita o que não sabe mostrando como descobriria.

> 💡 **Analogia:** Entrevista é jogo de dupla, não prova: o entrevistador quer jogar junto.

**Aula:** [buscar vídeo no YouTube](https://www.youtube.com/results?search_query=entrevista%20t%C3%A9cnica%20desenvolvedor%20j%C3%BAnior%20perguntas)

**Exercícios**

- [ ] Responda 10 perguntas comuns (event loop, REST, JOIN, estado no React...).
- [ ] Faça uma entrevista simulada com IA.
- [ ] Live coding de 30 minutos.
- [ ] Explique o projeto final em 3 minutos.
- [ ] Prepare perguntas para o entrevistador.
- [ ] Grave e reveja uma resposta.

**Desafio:** Faça uma entrevista simulada com uma pessoa real.

### Dia 129 · Os próximos 90 dias

Aprender é contínuo: rotina de candidaturas, projeto vivo, comunidade e freelas.

> 💡 **Analogia:** É academia: o resultado vem da frequência, não de um dia heroico.

**Aula:** [buscar vídeo no YouTube](https://www.youtube.com/results?search_query=como%20conseguir%20primeiro%20emprego%20programador)

**Exercícios**

- [ ] Crie uma planilha de candidaturas.
- [ ] Defina metas semanais (candidaturas, posts, funcionalidades).
- [ ] Participe de uma comunidade ou meetup.
- [ ] Ajude alguém que está começando.
- [ ] Escolha os 3 próximos estudos.
- [ ] Escreva a retrospectiva dos 6 meses.

**Desafio:** Escreva uma carta para você daqui a 90 dias.
