## Aulas

### Dia 121 · Descoberta e escopo

Projetos fortes partem de um problema real. MVP é a menor versão que já resolve esse problema.

> 💡 **Analogia:** MVP é o skate antes do carro: já leva a pessoa de um ponto ao outro.

**Aula:** [buscar vídeo no YouTube](https://www.youtube.com/results?search_query=como%20definir%20mvp%20projeto)

**Exercícios**

- [ ] Entreviste 1 usuário real (advogado, comerciante, restaurante).
- [ ] Escreva o problema em uma frase.
- [ ] Escreva 5 histórias de usuário.
- [ ] Liste o que fica fora do escopo.
- [ ] Defina como medir sucesso.
- [ ] Desenhe um protótipo em papel ou Figma.

**Desafio:** Valide o protótipo com o usuário.

### Dia 122 · Arquitetura e base

Antes de codar, decida stack, modelo de dados e contratos, e registre as decisões.

> 💡 **Analogia:** É a fundação antes das paredes.

**Aula:** [buscar vídeo no YouTube](https://www.youtube.com/results?search_query=arquitetura%20de%20software%20projeto%20full%20stack)

**Exercícios**

- [ ] Desenhe o diagrama da arquitetura.
- [ ] Escreva o schema do Prisma.
- [ ] Crie o repositório com CI desde o primeiro dia.
- [ ] Organize as tarefas no GitHub Projects.
- [ ] Configure os ambientes.
- [ ] Crie o seed.

**Desafio:** Escreva 3 ADRs com as principais decisões.

### Dia 123 · Funcionalidade principal

Entregue primeiro a fatia vertical (tela, API, banco) da funcionalidade mais importante.

> 💡 **Analogia:** Fatia de bolo: um pedaço com todas as camadas, em vez de assar só a massa inteira.

**Aula:** [buscar vídeo no YouTube](https://www.youtube.com/results?search_query=vertical%20slice%20desenvolvimento)

**Exercícios**

- [ ] Implemente o fluxo principal de ponta a ponta.
- [ ] Escreva os testes dele.
- [ ] Publique uma prévia.
- [ ] Colete feedback do usuário.
- [ ] Corrija o que apareceu.
- [ ] Anote o que aprendeu.

**Desafio:** Faça o usuário completar o fluxo sem a sua ajuda.

### Dia 124 · IA e diferenciais

A IA entra onde economiza tempo do usuário de forma mensurável, sempre com plano B.

> 💡 **Analogia:** A IA é o assistente do chef: corta e separa, mas o prato final passa pelo chef.

**Aula:** [buscar vídeo no YouTube](https://www.youtube.com/results?search_query=integrar%20ia%20em%20aplica%C3%A7%C3%A3o%20web)

**Exercícios**

- [ ] Integre o LLM na funcionalidade certa.
- [ ] Crie a avaliação (eval).
- [ ] Limite os custos.
- [ ] Revise a acessibilidade.
- [ ] Adicione monitoramento.
- [ ] Passe o checklist de segurança.

**Desafio:** Mostre o ganho de tempo da IA com números.
