## Aulas

### Dia 116 · Assistentes de código

Copilot, Claude Code e Cursor aceleram tarefas repetitivas. Seu valor está em especificar bem, revisar e testar.

> 💡 **Analogia:** É um estagiário muito rápido: você entrega a tarefa clara e confere tudo antes de assinar.

**Aula:** [buscar vídeo no YouTube](https://www.youtube.com/results?search_query=como%20usar%20ia%20para%20programar%20claude%20code%20copilot)

**Exercícios**

- [ ] Escreva uma especificação e gere um CRUD com IA.
- [ ] Revise linha por linha e anote 3 problemas.
- [ ] Peça os testes antes do código.
- [ ] Use a IA para explicar um código que você não escreveu.
- [ ] Crie um arquivo de regras do projeto (CLAUDE.md ou AGENTS.md).
- [ ] Meça o tempo da mesma tarefa com e sem IA.

**Desafio:** Rejeite uma sugestão da IA e escreva por quê.

### Dia 117 · Code review

Revisar é procurar bugs, falhas de segurança, legibilidade e testes faltando, com feedback gentil e específico.

> 💡 **Analogia:** É revisão de texto: o revisor não reescreve o livro, aponta onde o leitor vai tropeçar.

**Aula:** [buscar vídeo no YouTube](https://www.youtube.com/results?search_query=code%20review%20boas%20pr%C3%A1ticas)

**Exercícios**

- [ ] Monte seu checklist de revisão.
- [ ] Revise um PR de um projeto open source.
- [ ] Revise código gerado por IA procurando falhas de segurança.
- [ ] Comente com uma sugestão concreta.
- [ ] Responda a um review sem se defender.
- [ ] Quebre uma mudança grande em PRs pequenos.

**Desafio:** Contribua com 1 PR num projeto open source (documentação vale).

### Dia 118 · System design básico

Como sistemas crescem: cache, fila, balanceador, réplica de banco, CDN. O júnior precisa conhecer o vocabulário e as trocas.

> 💡 **Analogia:** É planejar um restaurante que vai de 10 para 1.000 clientes: mais cozinheiros, fila de pedidos, estoque perto.

**Aula:** [buscar vídeo no YouTube](https://www.youtube.com/results?search_query=system%20design%20para%20iniciantes)

**Exercícios**

- [ ] Desenhe a arquitetura do seu SaaS.
- [ ] Decida onde entraria um cache Redis.
- [ ] Coloque o envio de e-mails numa fila.
- [ ] Use CDN para imagens.
- [ ] Estime requisições por segundo.
- [ ] Liste os pontos de falha.

**Desafio:** Explique o design de um encurtador de URL em 10 minutos.

### Dia 119 · Filas, jobs e tempo real

Tarefas demoradas vão para filas e workers. WebSockets ou SSE mandam atualizações em tempo real.

> 💡 **Analogia:** Fila é a senha do cartório: ninguém fica parado no balcão esperando o documento ficar pronto.

**Aula:** [buscar vídeo no YouTube](https://www.youtube.com/results?search_query=filas%20bullmq%20redis%20node)

**Exercícios**

- [ ] Suba um Redis no Docker.
- [ ] Fila de envio de e-mails.
- [ ] Retry e fila de falhas.
- [ ] Job agendado.
- [ ] Notificação em tempo real com SSE.
- [ ] Webhook com assinatura verificada.

**Desafio:** Processe 1.000 jobs e meça o tempo.

## Dia 120 · Projeto: Upgrade de produção

**Problema:** Evolua seu SaaS com o que times reais usam e documente as decisões.

**Requisitos**

- [ ] Fila para notificações
- [ ] Cache numa rota lenta
- [ ] Notificações em tempo real
- [ ] Revisão crítica de um código gerado por IA, documentada

**Critérios de pronto**

- [ ] Performance medida antes e depois
- [ ] Documento de decisões técnicas (ADRs)

**Entrega:** _link do repositório ou deploy_
